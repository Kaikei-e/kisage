# 適合性サンプル

[必須反例 #1〜#60](required-counterexamples.md) は、構想書ドラフト v7 で詰めたシナリオ・期待値を保持する規範的なサンプル集である。[ADR 0005](../ADR/0005-cli-mcp-result-aggregation-and-verification-gates.md) によって検証ゲートとして採用され、純粋関数 PBT、Lean/Go DRT、Provider 適合性・障害注入、CLI/MCP 統合テストの共通入力仕様となる。

## 置き場と責任

| 置き場 | 内容 |
| :--- | :--- |
| [設計憲章](../PRINCIPLE.md) | 不変の原則・保証境界・非目標 |
| [ADR](../ADR/README.md) | 型・状態分類・権限・実行順序・失敗経路・証明前提の決定 |
| 本ディレクトリ | 固定番号付きのシナリオ・期待値・境界条件の具体例・対応 ADR |

サンプルは説明だけの任意例ではなく、ADR とともに満たす適合性条件である。実行可能なテストや証明そのものではないため、文書を置いたことを試験合格と扱わない。非公開の議論記録を参照せずに期待動作を確認できる状態を保つ。

## 更新方法

- 既存番号を維持し、追加は #61 以降とする。
- 期待値を変える場合は対応 ADR も更新し、理由と影響番号を記録する。
- テストを実装するときは対応サンプル番号を残し、前提・成功・失敗・結果不明の各分岐を検査する。
- 入力の具体表現や管理者復旧方式等が未確定なら、[ADR 0005 の Phase 0 決定事項](../ADR/0005-cli-mcp-result-aggregation-and-verification-gates.md#4-60件の必須反例スイートと開発フェーズゲート) に記録し、仮定で埋めて完了扱いしない。
